# MDA Colony Master Plan — 12.0m Boulevard Vastu Layout

Interactive CAD Master Plan Explorer for a **29,274.03 m² (38.45 Bighas / 35,011.44 Gaj)** residential township development adhering to Meerut Development Authority (MDA) subdivision norms.

---

## Key Highlights

- **12.0m (40'-0") Main Central Boulevard:** Upgraded from 9.0m to 12.0m, extending uninterrupted across the entire colony from the East Entrance Gate to the Western Boundary.
- **0% South-Facing Plots:** 100% of residential plots strictly face **East (74)**, **West (66)**, or **North (20)**, achieving complete Vastu Shastra compliance.
- **13.84% Parks & Open Greenery (4,051.50 m²):** Perfectly positioned within the mandated **13.0% – 15.0%** quota:
  - **Park-1 (Central Community Park):** 2,936.50 m² (10.03%) with jogging track, central pavilion, and yoga deck.
  - **Park-2 (North Buffer Park):** 650.00 m² (2.22%) ecological buffer along the sealed Chakroad compound wall.
  - **Park-3 (West Botanical Promenade):** 465.00 m² (1.59%) green buffer replacing the disadvantaged single-loaded western strip.
- **16.00% Road Wastage:** Optimized road network with double-loaded 9.0m (30') comb avenues, eliminating single-loaded dead corridors.
- **Mobile-First Experience:** Native touch pinch-to-zoom, touch pan, bottom-sheet plot inspector drawer, and dark/print mode toggles.
